# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in full. The link is the text; it is not restated here so that it cannot drift from the
original.

## In short

Everyone is welcome: contributors and users, whatever their experience, background or
identity. Be respectful, assume good faith, accept that a technical disagreement is about the
work and not about the person, and take correction gracefully — including from a maintainer
who turns out to be wrong.

Harassment, personal attacks, and publishing someone's private information are not tolerated,
in this repository or anywhere this project is represented.

## Scope

It applies in every project space — issues, pull requests, discussions, commit messages,
review comments — and whenever someone is representing the project in public.

## Reporting

Report a concern privately to **christophe@kadeya.com**. Do not open a public issue about someone's
conduct: it rarely helps the person reporting, and it never helps the person reported.

The maintainers will respond, keep the report confidential, and say what action they took.
Maintainers who do not follow or enforce this code in good faith can expect consequences
decided by the project's leadership.
